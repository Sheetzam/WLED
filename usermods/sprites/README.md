# Sprites by Anthony Sheetz / sheetzam

## Originally written for Arduino in 2016, now ported to WLED.

This is designed to be used on a 2D field of LEDs. It will create up to 8 sprites, which will move slowly from a random edge to the opposite edge. All other LEDs will cycle through RGB dimly.

Add sprites to your platform.io to compile in.

Can require a decent amount of RAM to work.
